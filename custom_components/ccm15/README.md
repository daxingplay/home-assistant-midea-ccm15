# Midea CCM-15 Thermostat for Home Assistant

This custom component integrates Midea CCM-15 central air conditioners with Home Assistant.

## Features
- Control and monitor your Midea CCM-15 thermostat from Home Assistant
- Supports temperature, HVAC mode, and fan mode
- Modern async and DataUpdateCoordinator architecture
- HACS compatible

## Installation
1. Copy the `ccm15` folder to your Home Assistant `custom_components` directory, or install via HACS (recommended).
2. Restart Home Assistant.

## Configuration
Configuration is done via the Home Assistant UI:
- Go to **Settings > Devices & Services > Add Integration**
- Search for "Midea CCM-15 Thermostat"
- Enter the host and port of your CCM-15 device
